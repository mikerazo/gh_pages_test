!!! warning "Not officially supported"
    These tools are provided as-is, for exploration. They aren't covered by support SLAs.

| Tool | What it does |
|---|---|
| [coffee-ratio](#coffee-ratio) | Works out how much coffee and water to use for a brew |
| [haiku-commit](#haiku-commit) | Writes git commit messages as haikus |
| [pirate-pr-review](#pirate-pr-review) | Reviews pull requests in pirate speak |
| [standup-scribe](#standup-scribe) | Turns rough notes into a daily standup update |

## How to install a skill

1. Download the tool's zip below.
2. **Claude Code:** unzip it into `~/.claude/skills/`, so you end up with `~/.claude/skills/<tool>/SKILL.md`.
3. **Claude app:** upload the zip in your skills settings.
